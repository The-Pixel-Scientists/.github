# The Pixel Scientists

**Substance is style. People, not programs.**

Insight scientists and data storytellers. Science is our background, with
PhDs in immunology, physiology and human genetics, and we bring that rigour
to all types of data. Data tells many stories. We find the one that answers
your question.

## What we do

- Data analysis, reporting and BI
- Data science and machine learning
- Visualisation
- Data pipelines and infrastructure (DataOps and MLOps)
- Scientific and technical writing
- Project management and C-suite reporting

## Fairfold

[Fairfold](https://github.com/The-Pixel-Scientists/Fairfold) is our
open-source suite of tools for funders, foundations and charities. Each tool
stands on its own, so an organisation can use one or switch on several, and
every tool runs on one shared platform.

- **Fairfold Grants** is the first, in development. Its first milestone is a
  complete funding round on synthetic data, and it is not yet ready for real
  data.
- The aim is for every tool to launch in 2027. Each has a folder in
  [`modules/`](https://github.com/The-Pixel-Scientists/Fairfold/tree/main/modules)
  that says what it will do.
- Code is AGPL-3.0-or-later and documentation is CC BY 4.0. Nothing is
  feature-gated, and self-hosters get everything the managed service has.

When you want help running them, you work with the people who built them.
